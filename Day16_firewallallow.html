Day 16 — Allow a Port Through Firewall

Purpose:

Firewalls are the first line of defense in system administration — controlling inbound and outbound network traffic.

However, different Linux distributions use different firewall tools:

  • Debian/Ubuntu: ufw (Uncomplicated Firewall)

  • RHEL/Fedora/CentOS: firewalld (firewall-cmd)

  • Legacy / Minimal systems: iptables

Bash


#!/usr/bin/env bash
#Debian: ufw, RHEL/Fedora/Rocky: firewalld/firewall-cmd, Legacy: 
#iptables

set -e

PORT=${1:-22}
# Determine which tool
if command -v ufw >/dev/null 2>&1; then
    FIREWALL="ufw"
elif command -v firewall-cmd >/dev/null 2>&1; then
    FIREWALL="firewalld"
elif command -v iptables >/dev/null 2>&1; then
    FIREWALL="iptables"
else
    echo "No supported firewall found..."
    exit 1
fi

# Allow port using tool
case "$FIREWALL" in
    ufw)
        echo "Detected UFW"
        sudo ufw allow "$PORT"
        sudo ufw reload
        ;;
    firewalld)
        echo "Detected firewalld"
        sudo firewall-cmd --permanent --add-port="${PORT}/tcp"
        sudo firewall-cmd  --reload
        ;;
    
    iptables)
        echo "Detected iptables (LEGACY)"
        sudo iptables -I INPUT -p tcp --dport "$PORT" -j ACCEPT
        sudo iptables-save > /etc/ipdatbles/rules.v4 2>/dev/null || true
        ;;    
esac

# Confirm
echo "Port $PORT successfully allowed through $FIREWALL"

Explanation:

  1. PORT=${1:-22} → sets the port, defaulting to 22 (SSH).

  2. command -v checks which firewall tool is installed.

  3. case block executes the correct rule based on the detected firewall.

  4. Automatically reloads rules (ufw reload, firewall-cmd --reload).

  5. Saves persistent rules for iptables if possible.

 

Python 3

#!/usr/bin/env python3
import subprocess, shutil, sys

port = sys.argv[1] if len(sys.argv) > 1 else "22"

# Determine which tool
if shutil.which("ufw"):
    firewall = "ufw"
elif shutil.which("firewall-cmd"):
    firewall = "firewalld"
elif shutil.which("iptables"):
    firewall = "iptables"
else:
    print("No supported firewall found...")
    sys.exit(1)

print(f"Detected {firewall} firewall")
# Allow port using tool

try:
    if firewall == "ufw":
        subprocess.run(["sudo", "ufw", "allow", port], check=True)
        subprocess.run(["sudo", "ufw", "reload"], check=True)
    elif firewall == "firewalld":
        subprocess.run(["sudo", "firewall-cmd", "--permanent", "--add-port={port}/tcp"], check=True)
        subprocess.run(["sudo", "firewall-cmd",  "--reload"], check=True)
    elif firewall == "iptables":
        subprocess.run(["sudo", "iptables", "-I", "INPUT", "-p", "tcp", "--dport", port, "-j", "ACCEPT"], check=True)
        subprocess.run(["sudo", "sh", "-c", "iptables-save > /etc/iptables/rules.v4"], check=True)
    # Confirm
    print(f"Port {port} successfully allowed through {firewall}")

except subprocess.CalledProcessError:
    print(f"Failed to alllow port {port} with {firewall}, Check Permission...")

Explanation:

  1. shutil.which() detects the presence of known firewall tools.

  2. Chooses the correct command set dynamically.

  3. Uses subprocess.run() for executing system commands securely.

  4. Includes error handling with try/except.

  5. Ensures persistence for iptables if rule file exists.
