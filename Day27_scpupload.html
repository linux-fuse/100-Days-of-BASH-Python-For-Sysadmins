Day 27 - Securely Copy Over Files Using scp

Transferring files securely between systems is a core daily task for system administrators.
Whether you’re pushing a configuration file to a remote server or fetching logs for analysis, scp (Secure Copy) is your friend.

Script #25 shows how to automate this securely using both Bash and Python, ideal for integration into larger deployment or backup workflows.

Bash


#!/usr/bin/env bash

# Ensure correct arguments
if [ $# -lt 2 ]; then
    echo "USAGE: ./script27-scp.sh localfile user@host:/path"
    exit 2
fi
LOCAL="$1"
REMOTE="$2"

# Perform secure copy
echo "Transferring files"
if scp "$LOCAL" "$REMOTE"; then
    echo "Transfer completed"
else
    echo "Transfer failed"
    exit 1
fi

Explanation

 

  • if [ $# -lt 2 ] → Ensures both local and remote arguments are passed.

  • scp "$LOCAL" "$REMOTE" → Securely copies the file to the remote path.

  • Uses SSH under the hood, ensuring encryption and authentication.

  • Clear output for successful or failed transfer.

 

 

Python 3


#!/usr/bin/env python3
import sys, os, subprocess
# Ensure correct arguments
if len(sys.argv) < 3:
    print(f"Usage {sys.argv[0]} localfile user@host:/path")
    sys.exit(2) 

local = sys.argv[1]
remote = sys.argv[2]
# Perform secure copy

if not os.path.exists(local):
    print(f"Error: local path {local} not found")
    sys.exit(1)

print(f"Transferring files from {local} -> {remote}")

try:
    subprocess.run(['scp', local, remote], check=True)
    print("Transfer completed")
except subprocess.CalledProcessError:
    print("Frenafer Failed")
    sys.exit(1)

Explanation

 

  • os.path.exists(local) — Verifies the source file exists before attempting transfer.

  • subprocess.run(['scp', ...], check=True) — Runs SCP command with error checking.

  • try/except — Captures and reports failures gracefully.

  • Same behavior as Bash script but easier to extend (e.g., logging, multiple targets).
