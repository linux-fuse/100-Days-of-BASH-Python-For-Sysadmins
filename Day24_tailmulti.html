Day 24 - Monitor Multiple Log

Script #22 implements a cross-language solution to follow one or more logs continuously. This allows administrators to observe system activity as it happens, improving response time to issues and reducing downtime.

Bash


#!/usr/bin/env bash

# Default log files if none are specified
LOGS=${@:-/var/log/syslog /var/log/auth.log}
# Verify that each log file exists
for log in $LOGS; do
    if [ ! -f "$log" ];then
        echo "$log file doesn't exist"
    fi
done 

#Confirm and show logs in real time
echo "Tailing logs: $LOGS"
tail -f $LOGS

Explanation

 

  • LOGS=${@:-...} – Uses all passed arguments; defaults to /var/log/syslog and /var/log/auth.log.

  • for log in $LOGS; do ... – Checks if each file exists; warns if missing.

  • echo "Tailing logs: $LOGS" – Shows which logs are being monitored.

  • tail -f $LOGS – Continuously prints new lines as they are appended to the logs.

 

Python 3


#!/usr/bin/env python3
import sys, subprocess, os
# Default log files if none are specified
logs = sys.argv[1:] or ['/var/log/syslog','/var/log/auth.log']
# Verify that each log file exists
for log in logs:
    if not os.path.exists(log):
        print(f"{log} file doesn't exist", file=sys.stderr)
print(f"Tailing logs {' '.join(logs)}")

# Run tail -f
try:
    subprocess.run(['tail', '-f'] + logs, check=False)
except KeyboardInterrupt:
    print("\nStopped logged monit")
except Exception as e:
    print(f"Error: {e}")

Explanation

  • logs = sys.argv[1:] or [...] – Accept log file arguments or use defaults.

  • os.path.exists(log) – Checks existence of each log; warns if missing.

  • subprocess.run(['tail','-f'] + logs) – Runs tail -f in Python to continuously display new log lines.

  • KeyboardInterrupt – Allows clean exit with Ctrl+C.

  • Exception – Catches unexpected errors (e.g., permission denied).
