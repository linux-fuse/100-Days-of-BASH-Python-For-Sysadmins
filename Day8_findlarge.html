Day 8 - Find Large Files on the System

Pupose:

As a system administrator, monitoring disk usage is vital. Sometimes, storage fills up unexpectedly due to large log files, backups, or misconfigured applications.

This script helps you find all files larger than a given size anywhere on your system.

By default, it lists files larger than 100 MB, but you can easily specify a different threshold (e.g., 500M, 2G).

Bash

#!/usr/bin/env bash

# Default size threshold (can be overridden by user input)
# Examples: 50M (megabytes), 1G (gigabytes)
SIZE=${1:-100M}

# Use 'find' to search for files larger than the specified size
# -type f: only regular files
# -size +$SIZE: matches files larger than given size
# -exec ls -lh {} \;: lists each matching file with human-readable size
# 2>/dev/null: suppresses permission-denied errors
# || true: ensures script exits gracefully even if find encounters issues
find / -type f -size +"$SIZE" -exec ls -lh {} \; 2>/dev/null || true

Explanation:

  • The + before $SIZE is crucial — it means “greater than.”

  • Running find / may take time; limit the search to specific directories for faster results (e.g., /var or /home).

  • Redirecting errors with 2>/dev/null keeps output clean when the script lacks permission for certain directories.

Python 3

#!/usr/bin/env python3
"""
Script: find_large_files.py
Purpose: Find files larger than a specified size on the system.
Usage: ./find_large_files.py [SIZE]
Example: ./find_large_files.py 500M
"""

import subprocess
import sys

# Read size argument from command line or default to 100M
size = sys.argv[1] if len(sys.argv) > 1 else '100M'

# Construct the 'find' command as a list for subprocess
# Note: We use the 'find' utility itself for reliability and performance.
cmd = [
    'find', '/',               # Search from the root directory
    '-type', 'f',              # Only look for regular files
    '-size', f'+{size}',       # Files larger than specified size
    '-exec', 'ls', '-lh', '{}', ';'  # List them in human-readable form
]

# Execute the command. check=False prevents crash if command returns non-zero
subprocess.run(cmd, check=False)

Explanation:

  • Added docstring and usage info.

  • Uses formatted f-string for readability.

  • Defaults to 100M just like the Bash version.

  • Safe subprocess call using list syntax instead of shell=True.
