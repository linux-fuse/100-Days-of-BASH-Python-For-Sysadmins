Day 23 - Count Pattern in log file<

This script pair provides a lightweight utility to count how many times a specific pattern appears in a log file.
It works for any log file and can be used in automation scripts or monitoring cron jobs.

Bash


#!/usr/bin/env bash
set -e
# logfile location
PATTERN=${1:-ERROR}
LOG=${2:-/var/log/syslog}

# Check if lof found
if [ ! -f "$LOG"];then
    echo "$LOG File not found"
    exit 1
fi

echo "Searching for pattern in log file"
COUNT=$(grep -c "$PATTERN" "$LOG" || true)
echo "Found $COUNT occurrences of $PATTERN in $LOG"

Explanation:

 

  • The first argument ($1) specifies the pattern to search (defaults to ERROR).

  • The second argument ($2) specifies the log file (defaults to /var/log/syslog).

  • grep -c counts how many lines match the given pattern.

  • || true ensures the script doesn’t fail if grep finds no matches or the file is missing.

 

Python 3


#!/usr/bin/env python3
import sys, re
# logfile location
pattern = sys.argv[1] if len(sys.argv) > 1 else "ERROR"
log_file = sys.argv[2] if len(sys.argv) > 2 else "/var/log/syslog"

# Check if lof found
try:
    with open(log_file, "r", errors="ignore") as f:
        count = 0
        for line in f:
            if re.search(pattern, line):
                count += 1
    print(count)
except FileNotFoundError:
    print(0)
except PermissionError:
    print(0)

Explanation:

  • In Python, we open the log file safely and use regular expressions to find matches.
  • The script counts lines just like grep -c, but it’s easier to expand later — for example, to filter by time or severity.
  • It handles missing files and permissions gracefully.
