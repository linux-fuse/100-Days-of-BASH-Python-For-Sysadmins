Day 2 — Simple Alert On Disk Space

Purpose

This script extends the previous disk monitor by adding real-time alert messages when usage crosses 90%.
Ideal for cron jobs or pipelines that need clear warnings or alert forwarding.

Bash


        #!/usr/bin/env bash
# Monitor disk usage and print alert if above threshold
THRESH=90
usage=$(df --output=pcent / | tail -1 | tr -dc '0-9')
echo "/ usage: ${usage}%"
if [ "$usage" -ge "$THRESH" ]; then
  echo "ALERT: disk usage high" >&2
  exit 1
fi

Explanation

  • >&2 redirects the alert message to stderr — useful for monitoring logs.

  • exit 1 ensures your automation tools detect the warning as a failure.

  • Everything else remains lightweight and dependency-free.

Python 3

#!/usr/bin/env python3
import shutil, sys, smtplib
THRESH=90
total, used, free = shutil.disk_usage('/')
pct = used*100//total
print(f"/ usage: {pct}%")
if pct >= THRESH:
    print("ALERT: disk usage high")
    sys.exit(1)

Explanation

  • Similar to Bash logic, using Python’s shutil module for cross-platform access.

  • Imports smtplib in anticipation of adding email alerts.

  • Could easily redirect to sys.stderr if desired:

     
    print("ALERT: disk usage high", file=sys.stderr)
