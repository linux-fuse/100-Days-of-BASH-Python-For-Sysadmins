Day 21 - Change Permissions Recursively

 

This script sets file and directory permissions for a specified path.
By default, it targets /var/www (a common web root) and applies mode 755, which gives read/write/execute to owner and read/execute to others.
The script recursively updates all subdirectories and files.

 

 

Bash


#!/usr/bin/env bash

#/home/joakim/projects/100-scripts/etc as default path
PATH=${1:-/home/joakim/projects/100-scripts/etc}
MODE=${2:-755}

# Apply recursive permission
/bin/chmod -R "$MODE" "$PATH"
# Confirm
echo "Perm set on $PATH to $MODE"

 

Explanation

  • #!/usr/bin/env bash → ensures the script runs with the system’s Bash shell.

  • PATH=${1:-/var/www} → uses first argument or defaults to /var/www.

  • MODE=${2:-755} → uses second argument or defaults to permission 755.

  • chmod -R "$MODE" "$PATH" → recursively applies the permission mode.

  • echo → confirms operation completion.

 

Python 3


#!/usr/bin/env python3
import sys, os
#/home/joakim/projects/100-scripts/etc as default path
path = sys.argv[1] if len(sys.argv) > 1 else '/home/joakim/projects/100-scripts/etc'
mode = int(sys.argv[1], 8) if len(sys.argv) > 2 else 0o755
# Apply recursive permission
for root, dirs, files in os.walk(path):
    try:
        # Try setting permission on dir itself
        os.chmod(root, mode)
        # Set permissions to all the files inside
        for f in files:
            os.chmod(os.path.join(root, f), mode)
    except PermissionError:
        print(f"Permission denied while processing: {root}")
# Confirm
print(f"Permission set on {path} to {oct(mode)}")

 

Explanation

 

  • import os, sys → for filesystem and argument handling.

  • Checks if arguments are given; if not, defaults to /var/www and 0o755.

  • os.walk(path) → iterates recursively through all folders and files.

  • os.chmod(root, mode) → applies permission mode to each directory.

  • For every file, it applies os.chmod(os.path.join(root, f), mode).

  • Wrapped in a try/except block t
