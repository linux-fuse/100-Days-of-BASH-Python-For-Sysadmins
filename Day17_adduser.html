Day 17 - Add New User

Creating new users is one of the most common administrative tasks in Linux.
However, admins need to handle a few important details:

  • Checking if the user already exists.

  • Ensuring home directory creation.

  • Optionally assigning groups or default shells.

This script automates user creation safely, with checks and clear feedback.
It supports all standard Linux systems using useradd.

Bash


#!/usr/bin/env bash
set -e

USER=${1:-newuser}
# Check if running as root
if [[ $EUID -ne 0 ]]; then
    echo "Please run as root"
    exit 1
fi 


# Check if user already exists, if not, add user
if id "$USER" &>/dev/null; then
    echo "$USER exists"
else
    useradd -m "$USER"
    echo "$USER added"
fi

Explanation:

 

  • set -e — exits immediately if any command fails.

  • USER=${1:-newuser} — assigns the first argument as username, or defaults to newuser.

  • [[ $EUID -ne 0 ]] — ensures script runs with admin privileges.

  • id "$USER" — checks if the user already exists.

  • If not found, it runs useradd -m to create the account and home directory.

 

Python 3


#!/usr/bin/env python3
import subprocess,os, sys

user = sys.argv[1] if len(sys.argv) > 1 else "newuser1"
# Check if running as root

if os.getuid() != 0:
    print("Please run as root")
    sys.exit(1)

# Check if user already exists, if not, add user
check_user = subprocess.run(["id", user], stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)

if check_user.returncode == 0:
    print(f"{user} exists")
else:
    subprocess.run(["useradd", "-m", user], check=True)
    print(f"{user} added")

Explanation:

 

  • os.geteuid() checks if the script is being run as root.

  • subprocess.run(["id", user]) returns success if user exists.

  • If not found, useradd -m creates the user and home directory.

  • check=True ensures script exits if useradd fails.
