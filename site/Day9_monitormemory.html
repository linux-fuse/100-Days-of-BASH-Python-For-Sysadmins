Day 9 — Display System Memory Usage

Purpose:

Monitoring memory usage is essential for maintaining system health and performance.
This script quickly shows how much RAM is in use, available, and the total amount — helping you identify memory bottlenecks or runaway processes.

The Bash version uses the free utility, while the Python version leverages the psutil library for a programmatic approach.

Utilities & Modules Used

free

  • A standard Linux command that displays system memory usage.

  • The -h flag shows values in human-readable format (e.g., MB, GB).

  • Useful for quick checks and integration in monitoring scripts or health reports.

Python’s psutil Module

  • psutil (process and system utilities) is a cross-platform library providing information on system utilization — CPU, memory, disks, and more.

  • Ideal for Python-based monitoring tools, dashboards, or automation systems.

Bash

#!/usr/bin/env bash

# Display memory usage in a human-readable format
# 'free' shows total, used, and free memory in the system
# The '-h' flag converts bytes into KB, MB, or GB automatically
free -h

Python 3

#!/usr/bin/env python3
"""
Script: check_memory.py
Purpose: Display total and used memory with percentage usage.
Requires: psutil (install via 'pip install psutil')
"""

import psutil  # Import psutil for system resource monitoring

# Retrieve virtual memory statistics
mem = psutil.virtual_memory()

# Convert bytes to megabytes for readability (1 MB = 1024^2 bytes)
total_mb = mem.total // 1024**2
used_mb = mem.used // 1024**2
percent = mem.percent

# Display memory usage summary similar to 'free -h'
print(f"Total: {total_mb}MB, Used: {used_mb}MB ({percent}%)")
