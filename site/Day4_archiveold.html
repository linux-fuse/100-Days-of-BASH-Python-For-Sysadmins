Day 4 — Aarchive, Clean Up Old Logs

Purpose

To automatically archive and clean up old logs older than 30 days, preserving disk space and maintaining system hygiene.

Bash

#!/usr/bin/env bash
find /var/log -type f -mtime +30 -print0 | 
xargs -0 tar -czf /tmp/old-logs-archive.tar.gz --remove-files || 
true
echo "Archived logs older than 30 days to /tmp/old-logs-archive.tar.gz"

Explanation

  • find /var/log -type f -mtime +30 → Finds log files older than 30 days.

  • -print0 | xargs -0 → Ensures filenames with spaces are handled safely.

  • tar -czf /tmp/old-logs-archive.tar.gz --remove-files → Creates a compressed archive and removes the originals.

  • || true → Prevents non-zero exit from stopping execution.

Python 3

#!/usr/bin/env python3
import subprocess, shlex
cmd = "find /var/log -type f -mtime +30 -print0 | 
xargs -0 tar -czf /tmp/old-logs-archive.tar.gz --remove-files"
subprocess.run(cmd, shell=True, check=False)
print("Archived logs older than 30 days to /tmp/old-logs-archive.tar.gz")

Explanation

  • Executes the same Bash pipeline within Python.

  • Keeps the logic identical, simplifying script migration.

  • check=False ensures the command won’t throw exceptions if no files match.

  • Ideal for embedding into larger Python-based maintenance scripts.
