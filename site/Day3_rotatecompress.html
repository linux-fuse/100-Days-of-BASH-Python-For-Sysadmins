Day 3 — Log Rotation

Purpose

Automate the rotation and compression of log files to prevent disk bloat.
This lightweight script compresses each .log file into a .gz archive and truncates the original to zero bytes.

Bash


        #!/usr/bin/env bash
# Compress and truncate logs in /var/log/
for f in /var/log/*.log; do
  [ -e "$f" ] || continue
  if [ ! -e "${f}.gz" ]; then
    gzip -c "$f" > "${f}.gz" && : > "$f"
    echo "Rotated $f"
  fi
done

Explanation

  • for f in /var/log/*.log: iterate over logs.

  • [ -e "$f" ] || continue: skip if no files.

  • gzip -c "$f" > "${f}.gz": compress safely, preserving original until success.

  • : > "$f": truncate the file.

  • Prints a confirmation for visibility.

Usage Example:

Python 3

#!/usr/bin/env python3
import glob, os, gzip, shutil
for f in glob.glob('/var/log/*.log'):
    gz = f + '.gz'
    if not os.path.exists(gz):
        with open(f,'rb') as src, gzip.open(gz,'wb') as dst:
            shutil.copyfileobj(src,dst)
        open(f,'w').close()
        print(f'Rotated {f} -> {gz}')

Explanation

  • Uses glob for pattern matching.

  • gzip.open(..., 'wb') creates the compressed file.

  • shutil.copyfileobj() streams file contents efficiently.

  • open(f,'w').close() clears the log file after compression.

  • Prints a rotation message for visibility.
