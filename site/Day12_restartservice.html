Day 12 — Check the Status of Multiple Systemd Services

Purpose: 

This script helps sysadmins verify the operational status of multiple Linux services managed by systemd.
It’s a time-saver when monitoring multiple critical daemons like web servers, SSH, or databases.

Bash


          #!/usr/bin/env bash
# Script: Check status of multiple systemd services
# Usage:
#   ./check_services.sh ssh nginx mysql
#   ./check_services.sh ssh,nginx,mysql
# If no arguments are provided, defaults to ssh, nginx, and mysql.

if [ "$#" -eq 0 ]; then
  # Default list of services
  SERVICES=("ssh" "nginx" "mysql")
else
  # Allow both comma-separated and space-separated service names
  IFS=', ' read -r -a SERVICES <<< "$*"
fi

# Loop through each service and display its systemd status
for SVC in "${SERVICES[@]}"; do
  echo "====================================="
  echo "Checking status for: $SVC"
  echo "-------------------------------------"
  # Display service status; suppress pager and errors for missing services
  systemctl status "$SVC" --no-pager 2>/dev/null || 
  echo "Service $SVC not found or inactive"
  echo
done

Explanation:

 

  • systemctl — The systemd utility to manage and inspect services.

  • IFS (Internal Field Separator) — Used to split input on commas or spaces.

  • read -a — Reads input into an array for looping.

 

 

Python 3


          #!/usr/bin/env python3
"""
Script: Check status of multiple systemd services
Usage:
    ./check_services.py ssh nginx mysql
    ./check_services.py ssh,nginx,mysql
If no arguments are provided, defaults to ['ssh', 'nginx', 'mysql'].
"""

import subprocess
import sys

# Default services to check
default_services = ['ssh', 'nginx', 'mysql']

# If arguments are passed, parse them; support commas and spaces
if len(sys.argv) > 1:
    # Join all args into one string, replace commas with spaces, then split
    args = ' '.join(sys.argv[1:]).replace(',', ' ')
    services = args.split()
else:
    services = default_services

# Loop through services and check each one
for svc in services:
    print("=====================================")
    print(f"Checking status for: {svc}")
    print("-------------------------------------")

    try:
        # Run systemctl status command
        result = subprocess.run(
            ['systemctl', 'status', svc, '--no-pager'],
            capture_output=True,
            text=True,
            check=False
        )

        # Print the status output if successful, otherwise show a message
        if result.returncode == 0:
            print(result.stdout.strip())
        else:
            print(f"Service {svc} not found or inactive.")
    except Exception as e:
        print(f"Error checking {svc}: {e}")

    print()

Explanation:

  • subprocess — Executes shell commands (here used to run systemctl).

  • sys — Accesses command-line arguments.

  • split(',') — Splits comma-separated values into a list.
