Day 7 - Clean /tmp Directory Older than N Days

Purpose:

Automate system cleanup by removing files older than a given number of days from /tmp.

Bash


          #!/usr/bin/env bash

# Default retention period: delete files older than 7 days unless specified
DAYS=${1:-7}

# Use 'find' to locate files/directories under /tmp that are older than $DAYS
# -mindepth 1 ensures /tmp itself is not deleted
# -mtime +$DAYS finds items modified more than N days ago
# -print lists what will be deleted
# -exec rm -rf {} \; deletes each found item
# '|| true' prevents the script from exiting if find fails
find /tmp -mindepth 1 -mtime +"$DAYS" -print -exec rm -rf {} \; || true

# Output a confirmation message
echo "Cleaned /tmp older than $DAYS days"

Explanation:

 

  • The use of -mindepth 1 avoids accidental deletion of /tmp itself.

  • The script is safe to run regularly (e.g., via cron).

  • Uses parameters, making it flexible.

 

 

Python 3


          #!/usr/bin/env python3
"""
Script: cleanup_tmp.py
Purpose: Remove files and directories in /tmp older than N days.
"""

import os
import time
import shutil
import sys

# Get number of days from argument, default to 7
days = int(sys.argv[1]) if len(sys.argv) > 1 else 7

# Calculate cutoff time in seconds
cutoff = time.time() - (days * 86400)  # 86400 seconds in a day

# Define the root temporary directory
root = '/tmp'

# Iterate through each file/directory in /tmp
for name in os.listdir(root):
    path = os.path.join(root, name)

    try:
        # Check if the modification time is older than the cutoff
        if os.path.getmtime(path) < cutoff:
            # Remove directories safely
            if os.path.isdir(path):
                shutil.rmtree(path)  # remove directory recursively
                print(f"Removed directory: {path}")
            else:
                os.remove(path)  # remove file
                print(f"Removed file: {path}")
    except Exception as e:
        # Ignore permission errors or other exceptions
        print(f"Skipped {path}: {e}")

print(f"Cleaned /tmp older than {days} days.")

Explanation:

  • Replaced os.rmdir() with shutil.rmtree() — handles non-empty directories.

  • Added exception printing to know what was skipped.

  • Added flexibility to accept a command-line argument like the Bash version.

  • Added docstring for clarity.
