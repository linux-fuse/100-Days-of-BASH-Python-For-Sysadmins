Day 6 - Syncing Directories

Purpose:

Backing up user data is a fundamental system administration task.
In this chapter, we’ll use rsync, a powerful file synchronization utility, to back up a directory.
You’ll see how the same job can be done with a short Bash script and a safe Python equivalent using the subprocess module.

Bash


                #!/usr/bin/env bash
# Bash script to synchronize /home/ directory using rsync.

SRC=${1:-/home/}                
# Use first CLI argument or default to /home/
DST=${2:-/tmp/backup_home/}     
# Use second CLI argument or default to /tmp/backup_home/

# Run rsync with archive and delete options to mirror directories.
rsync -a --delete "$SRC" "$DST"

# Notify completion.
echo "rsync finished"

 

Explanation:

  • “SRC=${1:-/home/} means use the first argument if provided, or default to /home/.”

  • “We use rsync with -a for archive mode — it keeps file permissions, timestamps, and ownership.”

  • “The --delete flag ensures that the backup is an exact mirror — removing old files.”

  • “Finally, it prints a simple message once done.”

 

Python 3


        #!/usr/bin/env python3
"""
Backup synchronization using rsync from Python.
Usage: python3 backup_sync.py [SRC] [DST]
Defaults: SRC=/home/, DST=/tmp/backup_home/
"""

import subprocess   # To execute external commands safely
import sys          # To handle command-line arguments

# Determine source and destination with defaults
src = sys.argv[1] if len(sys.argv) > 1 else '/home/'
dst = sys.argv[2] if len(sys.argv) > 2 else '/tmp/backup_home/'

# Build the rsync command as a list (safer than a single string)
cmd = ['rsync', '-a', '--delete', src, dst]

# Run the command
subprocess.run(cmd, check=False)

# Print success message
print("rsync finished")

 

Explanation:

  • “In Python, we use subprocess.run() instead of calling shell commands directly.”

  • “Passing the command as a list avoids shell injection risks.”

  • “It’s safer, more portable, and allows us to easily capture or log output later.”
