Day 1 — Check Disk Usage

Purpose

Monitor disk space on / and exit with a non-zero status if usage exceeds a defined threshold (default 85%).
Ideal for cron jobs, CI/CD health checks, and early warning scripts.

Bash


#!/usr/bin/env bash
THRESH=85
usage=$(df --output=pcent / | tail -1 | tr -dc '0-9')
echo "/ usage: ${usage}%"
if [ "$usage" -ge "$THRESH" ]; then
  exit 1
fi

Explanation

  • df --output=pcent /: prints usage percent for /.

  • tail -1: skips header.

  • tr -dc '0-9': removes the % symbol, leaving just numbers.

  • Comparison checks if usage ≥ threshold.

  • exit 1: non-zero exit code for failure alerts.

Python 3


#!/usr/bin/env python3
import shutil, sys
threshold = 85  # percent
total, used, free = shutil.disk_usage('/')
percent = used*100//total
print(f"/ usage: {percent}%")
if percent >= threshold:
    sys.exit(1)

Explanation

  • shutil.disk_usage('/'): built-in module returning total, used, free space in bytes.

  • Integer math avoids floating precision.

  • sys.exit(1) mirrors Bash’s non-zero exit behavior.
