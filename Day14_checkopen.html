Day 14 — Check Staus of Multiple ports

Purpose:

Monitoring open ports is a fundamental sysadmin task for network troubleshooting, service validation, and security audits. Script #14 demonstrates how to check whether TCP ports are open or closed on a Linux system using both Bash and Python approaches.

Bash


#!/usr/bin/env bash
# Script #14 - Multi-Port TCP Listener Check (Bash)
# Checks if one or more TCP ports are open/listening on the local Linux system.
# Usage: ./check_ports.sh 22 80 443

# Exit if no ports are provided
if [ $# -eq 0 ]; then
  echo "Usage: $0  [port2] ..."
  exit 1
fi

# Loop over all command-line arguments (ports)
for port in "$@"; do
  # ss -tln : list TCP listening sockets, numeric output
  # awk '{print $4}' : extract the "local address:port" column
  # grep -q ":$port$" : check if port appears at the end of the column
  # && / || : conditional to print OPEN or CLOSED
  ss -tln | awk '{print $4}' | grep -q ":$port\$" && \
    echo "Port $port: OPEN" || echo "Port $port: CLOSED"
done

Explanation:

 

  • ss -tln – shows TCP listening sockets numerically.

  • awk – extracts the local address and port column.

  • grep – searches for the specific port.

 

 

Python 3


#!/usr/bin/env python3
import sys, socket

# Ensure at least one port is provided
if len(sys.argv) < 2:
    print(f"Usage: {sys.argv[0]} port1 [port2 ...]")
    sys.exit(1)

# Check if TCP port is open
def check_tcp(port):
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.settimeout(0.5)
    result = s.connect_ex(('127.0.0.1', port))  # returns 0 if port open
    s.close()
    return result == 0  # True if open, False if closed

# Check if UDP port is bound
def check_udp(port):
    s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
    try:
        # Attempt to bind; if successful, port is closed
        s.bind(('127.0.0.1', port))
        s.close()
        return False
    except OSError:
        # If unsuccessful, port is in use → OPEN
        return True

# Loop through all ports provided
for arg in sys.argv[1:]:
    port = int(arg)  # Convert to integer
    tcp_status = "OPEN" if check_tcp(port) else "CLOSED"
    udp_status = "OPEN" if check_udp(port) else "CLOSED"
    print(f"Port {port}: TCP {tcp_status}, UDP {udp_status}")

Explanation:

 

  • socket module – creates TCP sockets and attempts a connection.

  • connect_ex – non-blocking, returns success/failure code.

  • Minimal dependencies, portable across Linux distros and Python versions.
