Day 26 - Download Retry Script

Script #24 introduces a resilient file downloader that retries multiple times before giving up — implemented in both Bash and Python. This makes it perfect for unattended automation, backup scripts, and update pipelines.

Bash


#!/usr/bin/env bash
URL=$1
OUT=${2:-/tmp/download.pdf}

# Check input
if [ -z "$URL" ]; then
    echo "USAGE: $0 URL [output file]"
    exit 1
fi

# Attempt download up to 5 times
for i in 1 2 3 4 5;do 
    echo "Attempt $i: Downloading $URL"
    if curl -fSL "$URL" -o "$OUT"; then
        echo "Saved to $OUT"
        break
    else
        echo "Attempt $i failed, retrying in 2 seconds..."
        sleep 2
    fi 
done

Explanation:

  1. URL=$1 and OUT=${2:-...} – Take URL and optional output file path.

  2. curl -fSL options:

    • -f → fail silently on HTTP errors

    • -S → show error message on failure

    • -L → follow redirects

  3. The loop retries 5 times, with a 2-second delay.

  4. The loop breaks immediately upon success.

  5. Properly echoes feedback for every attempt.

Python 3


#!/usr/bin/env python3
import requests, sys, time, os

# Check input
if len(sys.argv) < 2:
    print(f"USAGE: {sys.argv[0]} URL [output file]")
    sys.exit(1)

url = sys.argv[1]
out = sys.argv[2] if len(sys.argv) > 2 else '/tmp/download.pdf'

# Attempt download up to 5 times
for i in range(1, 6):
    try:
        print(f"Attempt {i}: Downloading {url}...")
        r = requests.get(url, timeout=10, allow_redirects=True)
        r.raise_for_status() # Raises exception for bad http requests

        #save content
        with open(out, 'wb') as f:
            f.write(r.content)

        print(f"Saved to {out}")
        break
    except requests.exceptions.RequestException as e:
        print(f"Attempt {i} failed: {e}")
        if i < 5:
            print("Retrying in 2 seconds..")
            time.sleep(2)
        else:
            print("All attempt failed, exiting...")
            sys.exit(1)

Explanation:

  1. requests.get(url, timeout=10, allow_redirects=True) — Fetch file safely.

  2. r.raise_for_status() — Fails cleanly on HTTP 4xx/5xx.

  3. Writes file in binary mode ('wb') to preserve format.

  4. Retries 5 times with 2-second pauses between failures.

  5. Provides clear status output for success/failure
