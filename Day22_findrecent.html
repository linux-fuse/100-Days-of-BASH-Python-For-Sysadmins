Day 22 - Find Recent Files

his script finds all files modified within the last N minutes on a Linux system.
It’s useful for:

Bash


#!/usr/bin/env bash
set -e

# Default to 60 minutes if no argument passed
MIN=${1:-60}

# Use find to locate files modified recently
/usr/bin/find / -type f -mmin -"$MIN" -print #2>/dev/null || true
#Confirm
echo "Search completed"

Explanation

  • MINS=${1:-60} → uses the first argument or defaults to 60 minutes.

  • find / -type f -mmin -"$MINS" → lists all files modified within the last N minutes.

  • 2>/dev/null → hides "Permission denied" errors for system directories.

  • || true → ensures the script continues even if find returns a non-zero exit (common when some paths are inaccessible).

  • Prints start and completion messages for clarity.

 

Python 3


#!/usr/bin/env python3
import subprocess, sys
# Default to 60 minutes if no argument passed
min = sys.argv[1] if len(sys.argv) > 1 else '1'

print(f"Searching for files modified in the last {min}...")
# Run the find command, suppressing permission errors
try:
    subprocess.run(
        ['find', '/', '-type', 'f', '-mmin', f'-{min}', '-print'],
        stderr=subprocess.DEVNULL,
        check=False
        )

except Exception as e:
    print(f"Error while trying to find: {e}")
# Confirm
print("Search completed")

Explanation

  • mins = sys.argv[1] if len(sys.argv) > 1 else '60'
    → accepts a user-specified number of minutes or defaults to 60.

  • subprocess.run([...], stderr=subprocess.DEVNULL)
    → runs find silently, ignoring “Permission denied” warnings.

  • check=False
    → ensures the program doesn’t exit on non-zero return codes (normal for find).

  • Exception handling gives a readable error message if something unexpected happens.
