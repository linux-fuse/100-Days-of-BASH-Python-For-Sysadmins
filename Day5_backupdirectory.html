Day 5 — Backup A Directory

Purpose

Create compressed backups of important directories with a single command — ideal for system snapshots, config preservation, or migrations.

Bash

#!/usr/bin/env bash
SRC=${1:-/etc}
DST=${2:-/tmp/backup-etc.tar.gz}

mkdir -p "$(dirname "$DST")"

tar -czf "$DST" -C "$(dirname "$SRC")" "$(basename "$SRC")"
echo "Backup created at $DST"

Explanation

  • Default arguments: /etc → /tmp/backup-etc.tar.gz.

  • tar -czf: creates gzip-compressed archive.

  • -C option: avoids long absolute paths inside the archive.

  • mkdir -p: ensures destination exists.

Python 3

#!/usr/bin/env python3
import tarfile, sys, os

src = sys.argv[1] if len(sys.argv) > 1 else '/etc'
dst = sys.argv[2] if len(sys.argv) > 2 else '/tmp/backup-etc.tar.gz'

os.makedirs(os.path.dirname(dst), exist_ok=True)

with tarfile.open(dst, 'w:gz') as tar:
    tar.add(src, arcname=os.path.basename(src))

print(f"Backup created at {dst}")

Explanation

  • tarfile.open(..., 'w:gz'): creates gzip-compressed archive.

  • tar.add(): recursively adds directory contents.

  • arcname: ensures neat folder name inside the archive.

  • Cross-platform: works on Windows, macOS, Linux.
