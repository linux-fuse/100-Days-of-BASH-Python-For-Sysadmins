Day 28 - Generate ssh Keys<

SSH keypairs are the backbone of secure, passwordless access in Linux and DevOps environments.
Instead of typing passwords every time you connect, you authenticate using a cryptographic keypair (a public and a private key).

This script automates key creation, ensuring consistency across systems while supporting user-defined output locations — ideal for bootstrapping new servers or setting up automated CI/CD agents.

Bash


#!/usr/bin/env bash

OUT=${1:-$HOME/.ssh/ansible-sample}
# Generate a new 2048-bit RSA keypair (no passphrase)
ssh-keygen -t rsa -b 2048 -f "$OUT" -N "" >/dev/null 2>&1

if [ $? -eq 0 ]; then
    echo "Keypair generated"
    echo "Public key:"
    echo "${OUT}.pub"
else
    echo "Failed to generate keypair" >&2
    exit 1
fi

Explanation 

  • OUT=${1:-$HOME/.ssh/id_rsa}
    → Sets default output location if none provided.

  • ssh-keygen -t rsa -b 2048 -f "$OUT" -N ""
    → Creates a new 2048-bit RSA keypair with no passphrase.

  • Redirects output for silent operation.

  • Displays success message and the generated public key.

 

Python 3


#!/usr/bin/env bash
import sys, subprocess, os

out = sys.argv[1] if len(sys.argv) > 1 else os.path.expanduser('~/.ssh/ansible-sample2')
os.makedirs(os.path.dirname(out), exist_ok=True)
# Generate a new 2048-bit RSA keypair (no passphrase)
print(f"generating ssh keypair at {out}")

try:
    subprocess.run(['ssh-keygen', '-t', 'rsa', '-b', '2048', '-f', out, '-N', ''], check=True)
    pubkey_path = f"{out}.pub"
    if os.path.exists(pubkey_path):
        with open(pubkey_path) as pub:
            print("\nPublic Key: \n", pub.read().strip())
    else:
        print("Public key not found")
except subprocess.CalledProcessError:
    print("Failed to generate keypass")
    sys.exit(1)

Explanation 

  • os.makedirs(..., exist_ok=True) → Ensures ~/.ssh directory exists.

  • Uses subprocess.run() with check=True for strict error handling.

  • On success, reads and displays the .pub file.

  • Cleaner, reusable, and extendable for multi-host key provisioning.
