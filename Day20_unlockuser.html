Day 20 - Unlock Existing User Account

Purpose:

This script unlocks a specified user account from a Linux system.
If no username is provided, the script displays usage information and exits.

Bash


#!/usr/bin/env bash

# Check if username is provided
if [ -z "$1"]; then
    echo "Usage: $0 username"
    exit 2
fi

# Attempt to unlock the user
passwd -u "$1" || true

# Confirmation message
echo "User $1 account unlocked"

Explanation:

 

  • Checks if the first argument ($1) exists; if not, prints usage and exits with code 2.

  • Runs passwd -u unlocks users account.

  • || true ensures script continues even if userdel fails.

  • Prints a confirmation message.

 

 

Python 3


#!/usr/bin/env python3
import sys, subprocess
# Retrieve username argument
user = sys.argv[1] if len(sys.argv) > 1 else ''

# Check for missing username
if not user:
    print("Provide user to unlock")
    sys.exit(2)

# Attempt to unlock user account
subprocess.run(['passwd', '-u', user])

# Confirmation message
print(f"User {user} account unlocked")

Explanation:

 

  • Imports sys for command-line argument handling and subprocess to run system commands.

  • Reads username from the first argument.

  • If no username is given, it prints an error and exits with code 2.

  • Executes passwd -u username via subprocess.run().

  • Prints confirmation once complete.
