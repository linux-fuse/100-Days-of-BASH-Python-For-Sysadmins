Day 10 - Kill Processes by Name

Purpose:

System administrators often need to terminate misbehaving or runaway processes.
Instead of manually finding the process ID (PID) and running kill, you can use pkill to kill processes by their name pattern directly.

This script simplifies that action — both in Bash and Python.

Bash

#!/usr/bin/env bash
# Script: kill_process.sh
# Purpose: Kill all processes matching a given name or pattern.
# Usage: ./kill_process.sh process_name

# Check if user provided a process name as argument
if [ -z "$1" ]; then
  echo "Usage: $0 process_name"
  exit 2
fi

# Use pkill with -f to match the full command line
# '|| true' prevents script from exiting with error if no process matches
pkill -f "$1" || true

# Confirmation message
echo "pkill issued for $1"

Explanation:

pkill

  • A command-line utility that terminates processes by name or pattern.

  • Part of the procps package, available on most Linux distributions.

  • Options:

    • -f: Match the full command line, not just the process name.

    • Exits with 0 if processes were matched and killed, or non-zero otherwise.

Python 3

#!/usr/bin/env python3
"""
Script: kill_process.py
Purpose: Kill all running processes matching a given name.
Requires: 'pkill' installed on the system.
Usage: ./kill_process.py process_name
"""

import sys
import subprocess

# Get process name from command-line arguments
name = sys.argv[1] if len(sys.argv) > 1 else ''

# Validate input
if not name:
    print('Usage: ./kill_process.py process_name')
    sys.exit(2)

# Run pkill -f 
# -f matches the entire command line for flexibility
# check=False ensures script won't crash if pkill finds no matches
subprocess.run(['pkill', '-f', name], check=False)

# Display confirmation message
print(f"pkill issued for {name}")

Explanation:

Python’s subprocess Module

  • The subprocess module allows Python to execute shell commands safely.

  • It’s useful when wrapping system tools inside Python logic for automation (e.g., kill monitoring, process restarts, etc.).
