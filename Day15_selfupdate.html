Day 15 - Detect System and Update

Purpose

This script automates the process of updating a Linux system by detecting the available package manager and running the appropriate update commands.

System administrators often manage multiple distributions — Debian, Fedora, Arch, etc. — each with its own package management tool. This script eliminates the need to remember or manually run distribution-specific commands.

The goal: One script to update any Linux system automatically.

Purpose:

System administrators often need to terminate misbehaving or runaway processes.
Instead of manually finding the process ID (PID) and running kill, you can use pkill to kill processes by their name pattern directly.

This script simplifies that action — both in Bash and Python.

Bash


#!/usr/bin/env bash
set -e
PKG=$( command -v apt || command -v dnf || command -v yum || command -v zypper || command -v pacman || command -v apk)

# Case statement to select package managers and install updates
case "$PKG" in 
    *apt)
        echo "Detected Debian/Ubuntu based on apt."
        sudo apt update && sudo apt upgrade -y
        ;;
    *dnf)
        echo "Detected Fedora-based based on dnf."
        sudo dnf upgrade --refresh -y
        ;;
    *yum)
        echo "Detected RHEL-based based on yum."
        sudo yum update -y
        ;;
    *zypper)
        echo "Detected OpenSUSE-based system based on Zypper."
        sudo zypper refresh && sudo zypper update -y
        ;;
    *pacman)
        echo "Detected Arc-based system based on pacman."
        sudo pacman -Syu --noconfirm
        ;;
    *apk)
        echo "Detected Apline-based system based on apk."
        sudo apk update && sudo apk upgrade
        ;;
    *)
        echo "Unsupported system..."
        exit 1
        ;;
esac

# Print confirmation
echo "System updated successfully."

Explanation:

  • set -e
    → Makes the script exit if any command fails (safety measure).

  • PKG=$(command -v apt || command -v dnf || ... )
    → Finds the first available package manager executable.

  • case "$PKG" in)
    → Branches logic depending on which package manager was found.

  • Each *apt), *dnf), etc. block runs update/upgrade commands specific to that manager.

  • *)
    → Default case: handles systems with unsupported or missing package managers.

 

Python 3

#!/usr/bin/env python3
#!/usr/bin/env python3

import subprocess, sys, shutil

pkg_managers = {
    "apt": ["sudo", "apt", "update", "&&", "sudo", "apt", "upgrade", "-y"],
    "dnf": ["sudo", "dnf", "upgrade", "--refresh", "-y"],
    "yum": ["sudo", "yum", "update", "-y"],
    "zypper": ["sudo", "zypper", "refresh", "&&", "sudo", "zypper", "update", "-y"],
    "pacman": ["sudo", "pacman", "-Syu", "--noconfirm"],
    "apk": ["sudo", "apk", "update", "&&", "sudo", "apk", "upgrade"]
}

# Detetect package manager
detected = None
for pm in pkg_managers:
    if shutil.which(pm):
        detected = pm
        break

if not detected:
    print("Unsupported system...")
    sys.exit(1)

print(f"Detected {detected}-based system")

# Try to run the update command, provide confirmation
try:
    subprocess.run(" ".join(pkg_managers[detected]), shell=True, check=True)
    print("System updated successfully")
except subprocess.CalledProcessError:
    print("System update failed, check permission or package sources")

Explanation:

  • shutil.which(pm)
    → Checks if the package manager exists on the system PATH.

  • The dictionary pkg_managers defines the update commands for each manager.

  • Once a manager is detected, it runs the corresponding update command using subprocess.run() with shell=True.

  • If none are found, exits gracefully.

  • Exception handling ensures clear feedback if the update fails.
