Day 13 — Wait for a TCP Port to Become Available

Purpose:

Wait for a service to accept connections (e.g., database, SSH, HTTP) — useful in deployment scripts, init containers, CI pipelines, or orchestrated startup sequences where one service must wait for another.

Bash


          #!/usr/bin/env bash
#
# wait_for_port.sh
# Wait for a remote TCP port to become open.
# Usage:
#   ./wait_for_port.sh [HOST] [PORT] [TIMEOUT_SECONDS]
# Examples:
#   ./wait_for_port.sh 127.0.0.1 22 30
#   ./wait_for_port.sh db.example.com 5432 60

set -u  # treat unset variables as an error

HOST=${1:-127.0.0.1}       # default host
PORT=${2:-22}             # default port (SSH)
TIMEOUT=${3:-30}          # default timeout in seconds

# Check if nc (netcat) is available; it's the fastest check path.
if ! command -v nc >/dev/null 2>&1; then
  echo "Warning: 'nc' (netcat) not found. Falling back to /dev/tcp (bash) or failing." >&2
  # Try bash built-in /dev/tcp if available:
  if [ -e /dev/tcp/127.0.0.1/1 ] 2>/dev/null; then
    USE_DEV_TCP=1
  else
    USE_DEV_TCP=0
  fi
else
  USE_DEV_TCP=0
fi

end=$((SECONDS + TIMEOUT))

# Loop until timeout; check port once per second
while [ "$SECONDS" -lt "$end" ]; do
  if [ "$USE_DEV_TCP" -eq 0 ]; then
    # Use nc in "scan" mode (-z). -w 1 sets a short connect timeout per try.
    if nc -z -w 1 "$HOST" "$PORT" >/dev/null 2>&1; then
      echo "Port $PORT on $HOST is open"
      exit 0
    fi
  else
    # Try bash's /dev/tcp pseudo-device (works in bash on many systems)
    # Redirect output to /dev/null and check if the file descriptor opens.
    if (echo > /dev/tcp/"$HOST"/"$PORT") >/dev/null 2>&1; then
      echo "Port $PORT on $HOST is open (via /dev/tcp)"
      exit 0
    fi
  fi

  sleep 1
done

# If we get here, timeout expired
echo "Timeout waiting for port $PORT on $HOST after ${TIMEOUT}s" >&2
exit 1

Explanation:

  • nc (netcat): quick TCP/UDP connectivity checks from shell.

  • Bash /dev/tcp/host/port: pseudo-device for quick connection attempts (works in many bash environments).

Python 3

#!/usr/bin/env python3
import socket, sys, time

host = sys.argv[1] if len(sys.argv) > 1 else '127.0.0.1'
port = int(sys.argv[2]) if len(sys.argv) > 2 else 22
timeout = int(sys.argv[3]) if len(sys.argv) > 3 else 30

# Esure timeout is numeric when added to time.time()
deadline = time.time() + float(timeout)

while time.time() < deadline:
    try:
        s = socket.create_connection((host, port), 2)
        s.close()
        print('Port open')
        break
    except Exception:
        time.sleep(1)
else:
    print('Timeout waiting for port')
    sys.exit(1)

Explanation:

  • Python socket: programmatic TCP connections, cross-platform.
